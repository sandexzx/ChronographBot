# ChronographBot

Telegram бот для ведения лога жизни с использованием AI для улучшения записей и генерации статистики.

## Функциональность

- ⏰ Автоматические напоминания каждые 10 минут
- 📝 Заполнение отчетов с улучшением через GPT
- 📊 Просмотр статистики за различные периоды времени
- 🤖 Автоматическое улучшение записей с помощью GPT
- 📈 Анализ и структурирование статистики

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` со следующими переменными:
```
BOT_TOKEN=your_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
ADMIN_ID=your_telegram_id_here
```

4. Запустите бота:
```bash
python bot.py
```

## Использование

1. Отправьте команду `/start` боту
2. Используйте кнопки для:
   - Заполнения отчета
   - Просмотра статистики
3. Выберите период для просмотра статистики
4. Получайте автоматические напоминания каждые 10 минут

## Структура проекта

- `bot.py` - основной файл бота
- `config.py` - конфигурация и промпты
- `requirements.txt` - зависимости
- `.env` - конфиденциальные данные (не включен в репозиторий)

## Примечания

- Бот доступен только для администратора
- Логи хранятся в памяти (в production версии рекомендуется использовать базу данных)
- Для работы требуется API ключ OpenAI
